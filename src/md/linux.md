# Linux

## Comandos Linux

### chmod : change mode

````sh
# Dar permissão de execução a um script
chmod +x script.sh

# Arquivo comum
chmod 644 arquivo.txt

# Script executável
chmod 755 script.sh

# Diretório acessível
chmod 755 pasta/

# Alterar permissões recursivamente
chmod -R 755 pasta/

# Alterar proprietário
sudo chown -R www-data:www-data storage

# Ver permissões
ls -l
````
